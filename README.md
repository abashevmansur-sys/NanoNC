# Проект NanoNC - альтернативный интерфейс для FluidNC

Альтернатива для тех, кого напрягает избыточность интерфейса FluidNC. Намерено не стал делать веб-интерфейс из-за особенностей взаимодействия браузера и станка (не созданы друг для друга). Интерфейс сделан отдельным приложением под Андроид смартфон (не засыпает). Приложенный исходный код позволяет скомпиллировать приложение под дугие операционные системы, например Android, iOS. Интерфейс работает с прошивкой FluidNC используя wi-fi и websocket.
Бонус:
Что бы подключение к wifi не требовало регистрации в сети, в файле прошивки FluidNC\src\WebUI\WebUIServer.cpp закоментировать строки:
// dnsServer.start(DNS_PORT, "*", WiFi.softAPIP());
// dnsServer.processNextRequest(); 

### Состав проекта в архиве `nano_ui_fluid_nc.7z`:
* **Установочный файл `NanoNC.apk` для смартфона**:
 1. Скопируйте `NanoNC.apk` на телефон.
 2. Установите, разрешив установку из неизвестных источников.
* **Исходный код интерфейса NanoNC в папке `nano_ui_fluid_nc`**: для запуска использовал VS Code + фреймворк Flutter. Код интерфейса находится в одном файле `nano_ui_fluid_nc/lib/main.dart`, включая картинки svg.
* **Файл `config.yaml`** настройки конкретно моего станка на прошивке FluidNC (для примера).

## 🛠 Для справки - по прошивке FluidNC (для примера прошивка моего станка)

При разводке платы используйте следующие пины, соответствующие настройкам в файле `config.yaml`:

### 1.1 Пины двигателей
| Ось | Функция | Пин (GPIO) |
| :--- | :--- | :--- |
| **X** | Step / Dir | 12 / 13 |
| **Y (1)** | Step / Dir | 14 / 27 |
| **Y (2)** | Step / Dir | 25 / 26 |
| **Z** | Step / Dir | 17 / 16 |
| **Enable** | Все оси | 15 |

### 1.2 Пины SD-карты (SPI)
* **CS**: 5
* **MOSI**: 23
* **MISO**: 19
* **SCK**: 18

## ⚙️ Технические детали
* **Ядро**: ESP32 Core v2.0.17.
* **Таймер**: Шаги генерируются аппаратным таймером на **Core 0**.
* **Стоп**: Функция `emergencyStop` отключает моторы и шпиндель (пин 4).
