# Проект NanoNC

Альтернатива для тех, кого напрягает избыточность интерфейса FluidNC.

### Состав проекта:
* **Интерфейс**: VS Code + Flutter.
* **Прошивка**: VS Code + PlatformIO (ESP32).
* **Приложение**: файл `NanoNC.apk`.

---

## 🛠 1. Установка прошивки

При разводке платы используйте следующие пины:

### 1.1 Пины двигателей
| Ось | Функция | Пин (GPIO) |
| :--- | :--- | :--- |
| **X** | Step / Dir | 12 / 13 |
| **Y (1)** | Step / Dir | 14 / 27 |
| **Y (2)** | Step / Dir | 25 / 26 |
| **Z** | Step / Dir | 17 / 16 |
| **Enable** | Все оси | 15 |

### 1.2 Пины SD-карты (SPI)
* **CS**: 5
* **MOSI**: 23
* **MISO**: 19
* **SCK**: 18

---

## ⚙️ Технические детали
* **Ядро**: ESP32 Core v2.0.17.
* **Таймер**: Шаги генерируются аппаратным таймером на **Core 0**.
* **Стоп**: Функция `emergencyStop` отключает моторы и шпиндель (пин 4).

> Весь код прошивки находится в одном файле: `src/main.cpp`.

---

## 📱 2. Установка интерфейса
1. Скопируйте `NanoNC.apk` на телефон.
2. Установите, разрешив установку из неизвестных источников.
   
> Код интерфейса доступен в `lib/main.dart` в одном файле, включая картинки svg.
