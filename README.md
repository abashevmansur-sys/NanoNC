Проект NanoNCАльтернатива для тех, кого утомляет избыточность и «дубовость» интерфейсов вроде FluidNC. Проект ориентирован на лаконичность и быстродействие.Состав архива:Интерфейс: Исходники мобильного приложения (VS Code + Flutter).Прошивка: Исходники для ESP32 (VS Code + PlatformIO).Android App: Готовый файл NanoNC.apk для установки.🛠 1. Установка прошивкиПри разводке платы обратите внимание на назначение пинов. В текущей конфигурации (src/main.cpp) используются следующие настройки:1.1 Распиновка двигателей (Stepper Motors)ОсьФункцияПин (GPIO)XStep / Dir12 / 13Y (1)Step / Dir14 / 27Y (2)Step / Dir25 / 26ZStep / Dir17 / 16ВсеEnable15 (LOW = ON)ШпиндельPWM4Примечание: Пин шпинделя поддерживает управление скоростью через analogWrite.1.2 Подключение SD-карты (SPI)Используются стандартные аппаратные пины ESP32:CS: 5MOSI: 23MISO: 19SCK: 181.3 Сетевые настройки (SoftAP)Контроллер создает собственную точку доступа:SSID: NanoNCPassword: 12345678Port: 80 (HTTP) / /ws (WebSocket)⚙️ Технические особенностиЯдро: ESP32 Core v2.0.17.Стабильность: Генерация шагов вынесена на аппаратный таймер 0 и жестко привязана к Core 0, чтобы избежать конфликтов с Wi-Fi стеком.Безопасность: Функция emergencyStop мгновенно блокирует моторы и принудительно отключает питание шпинделя.[!TIP]Весь код прошивки для удобства правки собран в одном файле: src/main.cpp.📱 2. Установка интерфейсаВозьмите файл NanoNC.apk из релиза и скопируйте на смартфон.Разрешите в настройках Android "Установку из неизвестных источников".Установите приложение.Для разработчиков: Весь код интерфейса и SVG-графика находятся в файле lib/main.dart.
